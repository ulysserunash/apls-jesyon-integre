APLS — VÈSYON 3 POU IPHONE, ANDROID AK ÒDINATÈ
Deviz: Inyon • Solidarite • Devlopman

APARÈY
- iPhone/iPad: Safari; Add to Home Screen.
- Android: Chrome; Install app / Add to Home screen.
- Windows/Mac/Linux: Chrome/Edge/Firefox/Safari; louvri lyen entènèt la.
- Menm aplikasyon responsive a sèvi sou tout aparèy sa yo.

PIBLIKE SAN PEYE SOU NETLIFY
1. Ouvri https://app.netlify.com/drop sou navigatè ou.
2. Konekte sou kont ou.
3. Telechaje ZIP APLS_Pou_Tout_Aparey_V3.zip la sou Netlify Drop.
4. Ouvri adrès .netlify.app ki parèt.
5. Sou telefòn, ouvri /kijan_enstale.html oubyen klike "Kijan pou enstale".

POU REPLIT
Telechaje ZIP APLS_Pou_Replit_V3.zip. Kreye yon pwojè Node.js epi mete fichye yo nan rasin pwojè a. Kouri "npm start". Fè yon deployment apati koòdone Replit, si plan ou a ofri opsyon an.

SEKIRITE
SA SE YON DEMO; PA ANTRE ENFÒMASYON REYÈL.
- Pa gen login ak baz done pataje.
- Done tès yo rete nan navigatè a (localStorage), pa nan yon sèvè.
- Lòt telefòn oswa òdinatè pap wè menm done yo.
- Pa itilize pou vrè manm, kotizasyon oswa plent konfidansyèl.
- Yon vèsyon pwodiksyon mande otantifikasyon, otorizasyon, baz done, backups, règleman konfidansyalite, ak audit.
- Lè sou entènèt ak HTTPS, paj ak ikòn app ka rete nan cache pou itilizasyon ki limite san entènèt.
