Enstale APLS sou aparèy ou

Inyon • Solidarite • Devlopman

📱 iPhone / iPad

  1. Ouvri lyen aplikasyon an nan Safari.
  2. Peze bouton Pataje / Share.
  3. Chwazi Add to Home Screen / Ajoute sou ekran dakèy.
  4. Konfime Add / Ajoute, epi ouvri ikòn APLS.

🤖 Android

  1. Ouvri lyen aplikasyon an nan Google Chrome.
  2. Peze meni ⋮ a.
  3. Chwazi Install app oswa Add to Home screen, selon aparèy la.
  4. Konfime epi ouvri ikòn APLS.

💻 Òdinatè

  1. Ouvri lyen aplikasyon an nan Chrome oswa Microsoft Edge.
  2. Nan ba adrès la oswa meni navigatè a, chwazi Install app / Enstale si opsyon an disponib.
  3. Sinon, itilize li kòm yon sit entènèt nòmal sou nenpòt navigatè modèn.
⚠️ Sa se demonstrasyon. Li ouvri sou tout twa kalite aparèy, men li pa senkronize done ant yo. Enfòmasyon tès yo sere lokalman nan chak navigatè. Pa antre non, nimewo telefòn, adrès, dokiman idantite oswa done finansye reyèl. Pou yon aplikasyon reyèl kote tout manm APLS pataje menm dosye, n ap bezwen yon baz done sekirize, kont pèsonèl ak otorizasyon pa wòl.
